## 追加された機能

### 物理的関係の高度計算
- ユークリッド距離と正規化距離
- 近接レベル（距離の逆数指標）
- 相対角度（0-360度）

### 動的内部状態
- 遊びたい度（新おもちゃ登場、休憩、疲労による変動）
- 疲労度（エネルギー消費、活動時間による変動）
- 好奇心パラメータ（個体差の表現）

### 環境認識
- 環境音の検知
- おもちゃの視認性判定
- 照明レベルの考慮

### 学習支援機能
- 行動履歴の自動追跡
- 連続行動回数のカウント
- 状態リセット機能

## 使用方法

```python
# 基本的な使用
env = CatToyEnv(chaser="cat", runner="toy", dummy=["dummy1"])
obs = env.reset()  # 17次元の組織化状態を取得

# 状態の解析
cat_pos = obs[0:2]      # [x, y]
toy_pos = obs[2:4]      # [x, y]
distance = obs[4]       # 正規化距離
playfulness = obs[9]    # 遊びたい度
fatigue = obs[10]       # 疲労度
```
