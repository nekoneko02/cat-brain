# 状態空間の整理 (Issue #127)

## 概要
このドキュメントでは、Issue #127で実装された組織化された状態空間の構造について説明します。

## 状態空間の構成

### 新しい状態ベクトル（17次元）

猫エージェント（`cat`, `optical-cat`, `pre-cat`）の状態空間は以下の17次元で構成されています：

#### 1. ねことおもちゃの物理的関係 (9次元)
| インデックス | 説明 | 範囲 |
|-------------|------|------|
| 0 | ねこのx座標 | 0 ~ width-1 |
| 1 | ねこのy座標 | 0 ~ height-1 |
| 2 | おもちゃのx座標 | 0 ~ width-1 |
| 3 | おもちゃのy座標 | 0 ~ height-1 |
| 4 | 正規化距離 | 0.0 ~ 1.0 |
| 5 | 近接レベル（距離の逆数） | 0.0 ~ 1.0 |
| 6 | 正規化相対角度 | 0.0 ~ 1.0 |
| 7 | 実際の距離 | 0 ~ max_distance |
| 8 | 角度（度→正規化） | 0.0 ~ 1.0 |

#### 2. ねこの内部状態 (3次元)
| インデックス | 説明 | 範囲 | 更新要因 |
|-------------|------|------|---------|
| 9 | 遊びたい度 | 0.0 ~ 1.0 | 新おもちゃ登場(+), 長時間遊び(-) |
| 10 | 疲労度 | 0.0 ~ 1.0 | エネルギー消費(+), 休憩(-) |
| 11 | 好奇心パラメータ | 0.0 ~ 1.0 | 性格特性（固定値） |

#### 3. 環境ノイズ・外部要因 (3次元)
| インデックス | 説明 | 範囲 | 説明 |
|-------------|------|------|------|
| 12 | 環境音の有無 | 0/1 | 大きな音があった場合 |
| 13 | おもちゃの視認性 | 0/1 | 照明・障害物による影響 |
| 14 | 照明レベル | 0.0 ~ 1.0 | 現在の照明強度 |

#### 4. 行動履歴 (2次元)
| インデックス | 説明 | 範囲 | 説明 |
|-------------|------|------|------|
| 15 | 直前の行動ID | 0 ~ n_actions | 最後に実行した行動 |
| 16 | 連続行動回数 | 1 ~ ∞ | 同じ行動を連続実行した回数 |

## 実装詳細

### StateSpaceクラス
`cat-dqn/state_space.py`に実装された組織化クラス：

```python
# 完全な状態ベクトルの取得
state_vector = state_space.get_complete_state(
    cat_pos=(x, y),
    toy_pos=(x, y),
    max_distance=max_dist,
    current_action=action_id,
    energy_change=delta_energy,
    # ... その他のオプションパラメータ
)
```

### CatToyEnvの変更点
1. `StateSpace`クラスのインポートと初期化
2. `observe()`メソッドの拡張（猫エージェント用）
3. 行動履歴の追跡
4. エネルギー変化の監視

### 設定ファイルの更新
`cat-game/public/common.json`：
```json
"observation_space": {
  "cat": {
    "description": "Organized state space: physical relationships (9) + internal state (3) + environmental factors (3) + action history (2) = 17 dimensions",
    "shape": [17]
  }
}
```

## 後方互換性

- **おもちゃエージェント**: 従来の8次元状態空間を維持
- **ダミーエージェント**: 従来の2次元状態空間を維持
- **既存コード**: 変更なしで動作

## 使用例

```python
# 環境の初期化
env = CatToyEnv(chaser="cat", runner="toy", dummy=["dummy1"])
obs = env.reset()

# 観測の確認
print(f"猫の状態次元: {len(obs)}")  # 17
cat_pos = obs[0:2]  # [x, y]
toy_pos = obs[2:4]  # [x, y]
distance = obs[4]   # 正規化距離
playfulness = obs[9]  # 遊びたい度
```
